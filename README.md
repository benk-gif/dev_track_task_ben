Text Combiner
Text Combiner is a simple Python app built with Flet. Enter a first and last name and press Combine to get a greeting.

Features:
- Combines first and last names.

Dependencies:
- Python 3
- Flet
- flet-audio

Install with:
pip install flet flet-audio


How to Run:
flet run --web main.py


Easter Eggs:
- WU + TANG – Flying images and music.
- BEN + KRAUS – Ben picture and music.
- SECRET + MODE – Secret terminal with EXIT and SELF DESTRUCT buttons.
